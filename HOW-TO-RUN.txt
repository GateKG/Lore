LORE — tome UI update (drop-in)
================================

Two files:
  ui.html   — the whole tome UI, rewritten page-turn engine + intro + colours + tabs
  lore.py   — recorder engine, UNCHANGED except two window background-colour lines
              (kills the black pre-paint flash). All recording code is byte-identical.

------------------------------------------------------------------
FASTEST — update an already-installed LORE (no rebuild)
------------------------------------------------------------------
1. Fully quit LORE (tray icon -> quit).
2. Copy  ui.html  into the install folder, replacing the old one:
       C:\Program Files\Lore\ui.html
   (lore.py loads ui.html from next to the .exe FIRST, so this override just works.)
3. Start LORE.
   The lore.py change only affects a sub-second pre-paint flash and needs a rebuild
   to take effect in the .exe; the ui.html base colour already covers it, so ui.html
   alone is enough for the update.

------------------------------------------------------------------
RUN FROM SOURCE (dev box)
------------------------------------------------------------------
   python lore.py
   (Python 3.11+, deps: pyaudiowpatch pillow pystray psutil pywebview; ffmpeg+ffprobe
   in ffmpeg\bin\ or on PATH.)  ui.html is picked up from the same folder.

------------------------------------------------------------------
FULL REBUILD (to bake it into a fresh installer for friends)
------------------------------------------------------------------
   Replace ui.html and lore.py in your build source, then run build.bat
   (pip deps -> PyInstaller onedir -> bundles ffmpeg -> Inno -> LoreSetup.exe).

------------------------------------------------------------------
VERIFY 60 FPS LIVE (on the real window)
------------------------------------------------------------------
   Press F8 (or launch with #fps in the URL) to toggle a live FPS / worst-frame
   readout in the top-right. Scroll the wheel to riffle and watch it hold.
   Also try: scroll one notch at a time, and scroll 4 fast notches — every notch
   turns exactly one page, at the pace you scrolled.
